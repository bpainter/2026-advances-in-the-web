# Backgrounds, v5

Smooth multi-color gradients with fine film grain, generated with Higgsfield (Soul v2) on 28 October 2026
from the Slalom palette and the inspiration in `docs/design/inspiration/v5/`. 2048 by 1152 JPEG.
The assignment of each file to a slide or demo section, with its palette and tone, is table 1.4 in
`docs/PRD-demos-v5.md`. Each title and section intro slide has its own file; every page of one demo
section shares its section's file.
