How to return an item

Most items can come back for free. Start within the return window.

Have your order number ready. Keep the tags on, and pack any free gifts that came with it.

  1. Start the return

    Open Orders and pick the item.

  2. Pick a reason

    Tell us what went wrong.

  3. Print the label

    We email a prepaid label.

  4. Pack the item

    Reuse the box if you can.

  5. Drop it off

    Take it to Canada Post.
